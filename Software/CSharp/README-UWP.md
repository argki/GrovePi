# GrovePi in C#

## Get the Packages

- Windows 10 IoT 向け C# ドライバライブラリは [GrovePi](https://www.nuget.org/packages/GrovePi/) として提供されています。
- 現行リリース版の NuGet パッケージは [こちら](https://www.nuget.org/packages/GrovePi/) から取得できます。

WinIoT をこれから始める場合は、[WinIoT と GrovePi の入門チュートリアル](http://www.dexterindustries.com/GrovePi/programming/getting-started-with-windows-iot-and-the-grovepi-winiot/) を参照してください。大きく 3 ステップに分かれています。

1. [WinIoT と GrovePi 入門](http://www.dexterindustries.com/GrovePi/programming/getting-started-with-windows-iot-and-the-grovepi-winiot/)
2. [PC と Raspberry Pi のセットアップ](http://www.dexterindustries.com/GrovePi/programming/getting-started-with-windows-iot-and-the-grovepi-winiot/getting-started-windows-iot-winiot-and-grovepi-setting-up-your-pc-and-pi/)

4. [さらに多くの WinIoT GrovePi サンプルと例](http://www.dexterindustries.com/GrovePi/programming/getting-started-with-windows-iot-and-the-grovepi-winiot/getting-started-windows-iot-winiot-and-grovepi-more-winiot-grovepi-samples-and-examples/)
