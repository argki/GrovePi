# GrovePi Trubleshooting Script

ここにあるスクリプトは、GrovePi でよく発生する問題を切り分けるためのものです。

テストを実行するには、まず complete_test.sh を実行可能にします。

```bash
sudo chmod +x complete_test.sh
```

続いて次のように実行します。

```bash
sudo ./complete_test.sh
```

すべてのテストを実行するには、メニューでオプション 5 を選択します。数分かかる場合があります。

テストが完了すると、Desktop 上に `log.txt` ファイルが作成されます。このファイルをメールに添付するか、フォーラムに投稿してください。

GrovePi についての詳細は `http://www.dexterindustries.com/grovepi` を参照してください。
