## How to contribute to GrovePi for Node.js

- 新しいチケットを作成したり pull request を送ったりする前に、まずは既存の議論がないか [issue](https://github.com/DexterInd/GrovePi/issues) を検索してください。同じ機能や問題に関するチケットが見つかった場合は、そちらに追記する形で参加してください。

- コーディングスタイルは [npmjs](https://docs.npmjs.com/misc/coding-style) で推奨されているスタイルに従ってください。

- 自由な発想で、楽しんでコントリビュートしてください :-)
